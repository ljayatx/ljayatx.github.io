Privacy Policy

Private Home Assistant. Last updated: September 27, 2026

This private home assistant is used by one person, its owner. It is not offered to the public.

What data it accesses

With the owner's permission, granted through Google sign-in, the assistant accesses the owner's Google Nest thermostat data through Google's Smart Device Management API. That includes current temperature, humidity, mode, and temperature settings. It can change the temperature setting and mode, but only when the owner asks and only within fixed safety limits.

How the data is used

The data is used only to answer the owner's own requests and to carry out the changes the owner asks for. To understand a request and write a reply, the assistant sends the request and the relevant thermostat data to Anthropic's Claude API. The data is not used for advertising, profiling, or any other purpose.

Sharing

Google user data is not sold, rented, or shared with anyone, except as needed to process the owner's requests as described above.

Storage and security

Access credentials are stored only on the owner's home computer and never published. No database of thermostat readings is kept. The owner can revoke access at any time from their Google Account permissions page or the Google Home app.

Google API Services User Data Policy

This assistant's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
